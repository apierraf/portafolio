# Adrian Pierra Fuentes — Portfolio

Personal portfolio site for Adrian Pierra Fuentes, Mobile Tech Lead (Flutter, Kotlin, Swift) and web developer.

Live site: https://apierraf.github.io/portafolio/

## Stack
Single-page bilingual (EN/ES) site built with plain HTML, CSS and JavaScript — no build step, no dependencies. Fonts loaded from Google Fonts (Bricolage Grotesque, Onest, JetBrains Mono).

## Local preview
Just open `index.html` in a browser — no server required.

## Deployment
Hosted for free on GitHub Pages, served from the `main` branch, root folder.
