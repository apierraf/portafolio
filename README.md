# Adrian Pierra Fuentes — Portfolio

Personal portfolio site for Adrian Pierra Fuentes, Mobile Engineer (Android, Swift, Flutter) and full-stack web developer.

Live site: https://apierraf.github.io/portfolio/

## Stack
Single-page site built with plain HTML/CSS/JS — no build step, no dependencies. Fonts loaded from Google Fonts (Fraunces, Inter, JetBrains Mono).

## Local preview
Just open `index.html` in a browser — no server required.

## Deployment
Hosted for free on GitHub Pages, served from the `main` branch, root folder.
